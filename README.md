# מרכז פיקוד אירועים - פיקוד העורף

## התקנה והפעלה

```bash
npm install
npm run dev
```

פתח את הדפדפן בכתובת: http://localhost:3000

## מבנה האפליקציה

- **דף ראשי** - לוח אירועים עם כל האירועים הפעילים, צבועים לפי פלוגה
- **דף אירוע** - פרטי האירוע המלאים עם אפשרות עדכון ויצוא
- **יצוא לוואטסאפ** - טקסט מפורמט בעברית להעתקה לוואטסאפ

## תכונות
- פתיחת אירוע עם כתובת בלבד
- ולידציה של רשימת עוגן
- צביעה לפי פלוגה (א/ב/ג/ד/אחר)
- יצוא לוואטסאפ לאירוע בודד ולכל האירועים
- כפתור פתיחת וואטסאפ וב
- שמירה ב-localStorage
